# Contributing

Open a pull request to `main` from your fork. Contributor changes require approval from @callumflack and passing checks. Contributors must not merge or push directly to main. Callum retains owner/admin access to push his own changes directly.

For a source or factual correction, identify the claim and exact source/paragraph ID, link the original publisher, supply the relevant date and explain what changes. Distinguish direct quotations, publisher framing, later recollection and inference. A refusal to answer is neither a denial nor an admission. Sharing responsibility does not necessarily admit prior knowledge.

Preserve original source IDs and citation locators. Add a dated new account rather than silently changing what a source previously said. Do not infer agreement from silence or missing documents. Full underlying staff sources and direct listening checks remain open.

Do not contribute full copyrighted articles, book excerpts, audio, PDFs or automatic transcripts without established republication permission. Prefer an original source URL, a short necessary excerpt and your own precise explanation. Do not include credentials, private research captures, personal filesystem paths or screenshots of private applications.

Edit `src/content/docs` and the corresponding `public/sources.json` or `public/claims.json` metadata where relevant. Run `npm run build`, `npm run check` and `npm run verify:public`.
