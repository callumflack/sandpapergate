Start with [llms.txt](/llms.txt), then follow a group index to the relevant [document Markdown](/documents/llms.txt). The [source manifest](/sources.json) includes collection status, original links, gaps and paragraph citation URLs. [llms-full.txt](/llms-full.txt) collects the readable pages.

## A prompt to copy

> Read the Sandpapergate archive at https://sandpapergate.callumflack-97f.workers.dev/llms.txt. Identify the sources relevant to my question, read the source pages and preserve their qualifications. Cite exact paragraph links and original publishers. Distinguish a source’s account from a finding or your inference. Say what is missing or not verified; do not treat an uncollected source as evidence.

## Public access

Agents with public web access can read these Markdown pages and original archive analysis. Underlying publisher text and recordings are not hosted here; follow publisher links and preserve their access and verification limits.

## Search

The Search button uses Nimbus’s Pagefind full-text index. It indexes the public pages in this edition. No remote MCP or HTTP search service is configured. Agents can browse the linked Markdown indexes directly.

## Limits

A list of source URLs is not proof that an agent read their contents. Ask for passages, not just source names. This collection is incomplete and captured source text remains subject to verification and republication review.
