## How this list is used

Add a dated source or a concrete new lead when one is found. State what it adds, its completeness and verification limits, and which claim it could affect. Keep unsuccessful search routes in the research ledger so later work resumes from the remaining lead. No new source hunting is required to start the current argument analysis.

The [Khawaja dossier](/questions/khawaja/) now separates earlier use, additional awareness, universal knowledge, coaching involvement, the response, investigation completeness, alleged intent and accountability. A source gap moves up when its answer could change one of those arguments. A search lead belongs with the missing source it might recover; it is not a separate priority.
