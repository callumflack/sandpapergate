This project assembles the major Sandpapergate documents, statements and recordings, with a timeline, participant indexes and unresolved questions. The aim is to make the evidence easier to inspect and cite. Conclusions remain the reader’s.

## Public edition

This is the public reference edition. Full captured text remains private; publication permissions, original recordings and extraction accuracy still require review. No accounts, chat service or external search backend are required.
