---
title: "Contemporary records and retrospective accounts"
description: "Date a source by when it was made, as well as the event it describes."
tableOfContents: false
---

A contemporary record was made at or near the time of the event it describes. A retrospective account describes an earlier event later. These labels concern timing, not automatic credibility.

An original interview is primary material for what the speaker said in that interview. It does not independently prove that every event described happened as recalled. Several publishers reproducing the same statement are not several independent witnesses.
